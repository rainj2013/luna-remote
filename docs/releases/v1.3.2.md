## 主要更新

### 连接分组与侧边栏

- 优化连接列表的树形层级，分组与连接通过缩进、分隔线和更清晰的标题样式区分，方便浏览和定位。
- 分组标题新增新建连接入口，可以直接向指定分组添加连接。
- 通过侧边栏工具栏、右键菜单或原生菜单新建连接时，默认使用当前选中的分组或连接所属分组，减少重复选择。
- 保存连接后自动展开所属分组，便于立即查看新建或编辑的连接。
- 优化分组与连接的选中状态，分组操作和连接操作的目标更加清晰。

### 会话标签与主题

- 增强当前会话标签的背景、边框和阴影，让活动会话在多个标签之间更加醒目。
- 同步优化浅色与深色主题中的标签对比度、关闭按钮和侧边栏连接样式。

### 安装包说明

- macOS 提供 Intel（x64）和 Apple Silicon（arm64）DMG，请根据处理器类型选择；两个包均使用开发者签名并通过 Apple 公证。
- Windows 用户建议优先选择标准版；系统未预装 WebView2 或需要特殊离线环境安装包时再选择 `with-webview2` 版。Windows 安装包仍未签名。
